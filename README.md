# API Pet

**一个 Windows 桌宠形式的 AI 工具箱，集站点管理、账户余额、模型对话、AI 绘图和本地 API 路由于一体。**

把分散在不同站点的 API、密钥和模型集中管理，通过桌面上的宠物随时查看账户、打开对话或生成图片。需要连接其他 AI 客户端时，也可以启用本地聚合网关。

当前版本：`0.1.114` · 文档更新日期：2026-10-06。

详细操作说明：[HELP.md](HELP.md)

## 站点与密钥管理

- 集中管理多个 AI Provider，分别配置登录地址和 API 请求地址。
- 支持粘贴网址、API Key 和站点名称快速录入，也支持识别 Markdown 链接。
- 每个站点可保存多组 API Key 和备注，选择当前使用的密钥。
- 测试连接并获取模型列表，查看站点连接状态。
- 支持单独或全部折叠站点；折叠全部后，可长按拖动或使用箭头排序，顺序自动保存。

## 账户与用量

- 支持 Sub2API、New API 和 AIHub 的账户连接、余额查询及令牌导入，连接时自动识别支持的站点类型。
- 查看余额、剩余额度及站点提供的今日消费和请求统计。
- 支持手动刷新、定时刷新、低余额阈值设置，以及批量连接账户。
- 记录通过 API Pet 发起的请求次数、Token 用量、响应时间和可获取的费用信息。
- 可配置自定义余额接口，也可仅保存站点，用于对话、绘图和转发。

账户数据的可用范围取决于站点接口；站点账户统计与 API Pet 本地请求统计分别来自不同的数据来源。

## 模型对话

- 在宠物上方打开对话气泡，按站点、Key 和模型选择请求目标。
- 对话中选择的 Key 独立于站点默认 Key，并获取该 Key 可用的模型。
- 支持连续文本对话，以及向支持图片输入的模型发送图片。
- 支持选择或拖入图片，兼容 `chat/completions` 和 `responses` 两种接口。
- 支持清空对话上下文；请求失败时恢复输入，便于重试。

内置对话直接调用所选站点，无需启用本地 API 路由。

## AI 绘图

- 在对话窗口切换到绘图模式，支持文生图和图生图。
- 已适配 OpenAI 兼容 Images API，以及 Gemini、Seedream、Grok 和 SenseNova 的部分绘图模型。
- 根据模型提供分辨率、比例、质量、数量和其他可用参数。
- 生成图片可放大查看、保存到本地或复制到系统剪贴板。
- 支持多张生成，部分失败时保留成功结果；绘图记录独立于文本对话上下文。

实际可用模型、参数与生成能力取决于所选站点和上游模型。

## 桌宠交互

透明、无边框的桌宠窗口支持拖动、置顶和隐藏。通过宠物按钮或系统托盘，可以打开对话、控制面板及退出程序。

宠物会在连接账户、获取模型、处理请求和查询余额时播放相应动画。对话与控制面板支持调节高度，控制面板还支持调节宽度。

## 本地聚合网关

为其他 AI 客户端或 Coding Agent 提供统一的本地入口：`http://127.0.0.1:8787/v1`。

- 支持模型列表、`chat/completions` 和 `responses` 接口，以及流式响应透传。
- **统一模型模式**：客户端使用 `Pet model`，在 API Pet 中选择实际使用的站点和模型。
- **模型路由模式**：客户端使用真实模型名，按配置选择对应站点。
- 使用独立的本地统一 Key；路由默认关闭，按需启用。

统一模型模式下，客户端请求端点需要与所选上游格式一致。

## 启动与说明

安装 Node.js 18 或更新版本后，双击 `启动 API Pet.bat`，脚本会检查并安装所需依赖。也可以在项目目录运行：

```powershell
npm install
npm start
```

启动后，桌面会显示宠物，Windows 任务栏通知区域也会显示 API Pet 图标。打开“设置”添加站点，或打开“对话”选择模型开始使用。

## 配置与数据

配置默认保存在 `%APPDATA%\api-pet\api-pet.json`，包含站点信息、API Key、账户授权凭据及路由配置。该文件包含私密信息，请勿公开分享。

配置没有云同步功能。模型调用和账户查询会连接你配置的上游站点；发送的文字和图片会传给所选模型。需要保留的对话内容和生成图片，请在退出前自行保存。

源码没有预置中转站地址或推广链接；界面中的站点名称、地址和模型列表来自本地配置及上游接口。
